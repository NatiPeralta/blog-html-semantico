# 📰 Blog Semântico com HTML5 e CSS3

Projeto de um blog de artigos e notícias desenvolvido com o objetivo principal de praticar e aplicar as **boas práticas de HTML semântico**, acessibilidade e estruturação correta de conteúdo para motores de busca (SEO).

O projeto foi construído como atividade prática durante o curso **Formação Front-end** ministrado pelo portal **Hora de Codar** na Udemy.

---

## 🚀 Destaques do Projeto

- 🏷️ **Uso Extensivo de Tags Semânticas:** Estruturação utilizando tags com significado contextual claro, como `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>` e `<footer>`.
- ♿ **Acessibilidade & SEO:** Melhoria da navegação por leitores de tela e otimização para indexação de motores de busca através da hierarquia correta de títulos (`<h1>` a `<h3>`).
- 🎨 **Estilização e Leitura Fluida:** Layout limpo focado na usabilidade, leitura confortável dos artigos e barra lateral (`<aside>`) para conteúdos secundários.
- 📐 **Design Responsivo:** Adaptação da estrutura do blog para telas de computadores e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica, acessível e otimizada.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização de artigos, menus, tipografia e regras de layout responsivo.
- **[Git & GitHub](https://github.com/):** Controle de versão do código.
